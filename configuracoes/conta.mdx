A tela **Configurações → Conta** reúne os dados gerais da conta. Só administradores acessam essa tela.

## Configurações gerais

| Campo | O que é |
| --- | --- |
| **Nome da Conta** | O nome da sua empresa ou operação dentro do ChatClean. |
| **Idioma do site** | O idioma padrão da conta. Cada pessoa pode escolher outro idioma no próprio [perfil](/configuracoes/perfil). |

Depois de alterar, clique em **Atualizar configurações**.

## ID da Conta

O **ID da Conta** é o número que identifica a sua conta. Você precisa dele para montar integrações pela [API](/api-reference/introduction), porque os endereços da API levam esse número, por exemplo `https://chat.chatclean.com.br/api/v1/accounts/ID_DA_CONTA/conversations`.

Para gerar o token que autentica essas chamadas, veja [Token de acesso](/configuracoes/perfil#token-de-acesso).
