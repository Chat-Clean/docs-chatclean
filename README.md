# Documentação do ChatClean

Documentação do [ChatClean](https://chat.chatclean.com.br), o CRM omnichannel com IA da ChatClean. Site em Mintlify, servido em https://docs.chatclean.com.br.

## Rodar localmente

```bash
npx mint dev            # pré-visualização em http://localhost:3000
npx mint broken-links   # confere os links internos
```

Instruções para quem edita: `AGENTS.md`.
